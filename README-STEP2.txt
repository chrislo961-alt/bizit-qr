# SoloBizKit – Step 2: QR Code Generator V3

Upload the `qr-code-generator` folder to the ROOT of your existing repository and overwrite the current folder.

V3 adds:
- URL, Wi-Fi, Text, Email, Phone, SMS and vCard/contact QR types
- Live preview
- Logo upload
- Logo sizing and padding
- High/medium/low error correction controls
- Custom foreground/background colors
- Color presets
- Transparent background
- Contrast warning
- 512–2048px export
- PNG download
- SVG download, including embedded logo
- Copy encoded content
- Improved mobile layout
- Updated SEO title, description, FAQ schema and WebApplication schema
- No account/backend required

Important:
The QR generator uses qrcode@1.5.4 from jsDelivr. Users need internet access for the library to load.
Always scan-test logo/custom-color QR codes before printing.
