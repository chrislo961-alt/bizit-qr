Choose the right mode

  1. BalancedRe-renders pages at practical quality. Best default for scans and image-heavy PDFs.
  2. Smaller fileUses lower image resolution and JPEG quality for stronger compression.
  3. LosslessRe-packs the document without intentionally reducing visible page quality.
Browser limits: up to 100 MB and 150 pages for Balanced/Smaller. Lossless may handle larger page counts, but very complex files can still exceed browser memory.

Compress a PDF without pretending every file is the same

PDF size depends on what is inside the document. Scanned pages and large images often have more room for reduction than a PDF that is already optimized. Balanced and Smaller modes trade some visual fidelity and PDF features for a lower file size; Lossless mode keeps the original page structure where possible.
