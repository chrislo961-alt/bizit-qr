How to compress a PDF online

Choose your PDF, select Balanced, Smaller file or Lossless, then run the compressor. When useful compression is possible, the tool shows the original size, new size and percentage saved before you download the result.

Balanced, smaller-file and lossless PDF compression

Balanced is the practical default for many scanned or image-heavy documents. Smaller file uses lower image resolution and quality to aim for a stronger reduction. Lossless keeps the original page structure where possible and can help with some PDFs without intentionally lowering visible page quality. Because PDF files can contain very different types of content, no compression method can guarantee the same reduction for every document.
