SoloBizKit Step 5 – Three New Tools

Upload all three folders to the ROOT of the repository:

/invoice-generator/
/profit-margin-calculator/
/hourly-rate-calculator/

Tools:
1. Invoice Generator
   - Live invoice preview
   - Multiple currencies
   - Tax
   - Print / Save PDF through browser
   - No backend

2. Profit Margin Calculator
   - Profit
   - Margin
   - Markup
   - Target selling price

3. Hourly Rate Calculator
   - Income goal
   - Expenses
   - Billable utilization
   - Weeks off
   - Buffer/profit
   - Required hourly rate

The next site patch should add these tools to the homepage, navigation, internal links and sitemap.
