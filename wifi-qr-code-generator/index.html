How a Wi-Fi QR code works

A Wi-Fi QR code stores the network name, security type and password in a format compatible scanners can understand. It can make guest Wi-Fi access quicker because visitors do not need to type the password manually.

Before you publish or print it

  • Scan-test the QR code on multiple phones.
  • Keep clear white space around the QR code.
  • Use a destination that works well on mobile.
