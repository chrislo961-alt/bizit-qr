SoloBizKit QR Generator V4 – Simplified UX

Upload the qr-code-generator folder to the ROOT of the existing GitHub repository
and overwrite the existing qr-code-generator folder.

Main changes:
- Three clear steps
- Much less visual clutter
- Advanced options hidden by default
- Simpler preview
- Three simple size choices
- Only the most common QR types visible
- Logo moved under Advanced options
- PNG and SVG remain available
- Existing analytics/consent files remain compatible
- No backend required

Designed specifically for users who may not be technically confident.
