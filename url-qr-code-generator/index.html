Create a QR code for any website link

A URL QR code stores a web address in a format phones and other QR scanners can read. When someone scans the code, their device can open the encoded link. This makes QR codes useful when you want to connect something physical, such as a flyer or package, to a website.

How to make a QR code for a URL

Paste the final public web address into the field above and generate the code. Include the full URL, preferably beginning with https://. Then scan the finished QR code with your phone to confirm that it opens the exact page you expect.

Where to use a URL QR code

Website QR codes can be useful on posters, flyers, product packaging, receipts, signs, event materials, menus and business cards. Link directly to the most useful mobile-friendly page instead of forcing visitors to navigate through several pages after scanning.

Tips for reliable QR code scanning

  • Use the final URL before printing large quantities.
  • Scan-test the QR code on more than one phone when possible.
  • Keep clear white space around the code.
  • Make the code large enough for the expected scanning distance.
  • Avoid placing a QR code over a busy image or low-contrast background.
  • For colors, logos, PNG/SVG downloads and other QR types, use the full free QR Code Generator.

Free URL QR code generator FAQ

How do I make a QR code for a website?

Paste the website URL above, generate the QR code and scan it with a phone before sharing or printing it.

Can I create a QR code for a link for free?

Yes. The current SoloBizKit URL QR Code Generator is free and does not require a SoloBizKit account.

Can I print the QR code?

Yes. Before printing, test the code and make sure it has enough size, contrast and clear space to scan reliably.

Should I link to my homepage?

Not necessarily. A QR code is usually more useful when it sends the scanner directly to the page that matches the purpose of the sign, flyer, product or campaign.
