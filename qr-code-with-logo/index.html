Using a logo in a QR code

A logo can make a QR code feel more branded, but it also covers part of the code. Keep the logo reasonably small and always scan-test the final exported image before using it in print.

Before you publish or print it

  • Scan-test the QR code on multiple phones.
  • Keep clear white space around the QR code.
  • Use a destination that works well on mobile.
